FLUJO DE TRABAJO

Iniciar un proyecto con agentes

  1. 1
    Prepara el paquete de trabajo

    Genera el brief, índice de fuentes y prompt del proyecto.

  2. 2
    Abre una terminal en esta carpetaopencode
  3. 3
    Solicita el flujo al coordinador

    Lee workspace/projects/<ID>/PROMPT_OPENCODE.md y empieza por el plan.

  4. 4
    Revisa e importa el borrador

    Abre Borrador y exportación para cargar BORRADOR.md.

i

MCP de navegador: el proyecto incluye la configuración de Playwright MCP en opencode.json. La primera ejecución puede descargar el paquete del servidor y navegador, y requiere que OpenCode y un proveedor/modelo ya estén configurados. Navegar con el navegador no garantiza que una cita sea verdadera: el agente debe abrir y validar cada fuente.
